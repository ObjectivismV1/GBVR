Ghostbusters VR: Player Guide

Start and move
• Run INSTALL.cmd after extracting the zip. Start SteamVR and connect the headset before launching the game. To update, run the
new installer: settings are kept.
• Left stick walk; click it to toggle sprint. Right stick flick = snap turn (VR settings > Play > Snap turn off = smooth turn). B jump; tap A
interact. Crouch by ducking.
Fight and gear
• Right trigger fire; left trigger alternate fire (the Boson Dart on the proton gun). With the PKE out, right trigger scans.
• Right stick click = capture a ghost; while holding it, squeeze the left trigger fully = slam. (Play settings can make capture click-on /
click-off.)
• Two-hand aim: bring the left hand to the drawn gun and hold the left grip. Release the grip to return to one-hand aim.
• X = trap: left hand at the left hip takes it, swing out and release to throw. Tap Y to take out / put away the PKE. Hold A, point with
the right stick, release = weapon wheel.
• Vent: hand over a shoulder plus grip. Holster / draw: right hand over the right shoulder, trigger and grip together. Story scenes may
put the gun away for a while.
• Hold Y: right stick = D-pad; right stick click = vent; right B = HUD on / off; right A = select / back.
Menu and settings
• Left hand beside the left ear + left grip, hold still about half a second (or F12). Point with the right hand; trigger clicks; right stick
scrolls; A closes.
• VR SETTINGS (bottom of the menu): Start (measure height, recenter, objectives), Play (turn, sprint, handedness, seated, capture,
comfort), View (enemy health, HUD, resolution, buzz), Help. F4 headset view; F9 recenter; Ctrl+F9 measure height.
Other headsets and controllers
• The mod needs SteamVR. Made and played on Quest 3 (Touch controllers) through Virtual Desktop; every other headset and
controller below is set up from SteamVR's own data and tested by computer only, so please report anything odd.
• Pico, Rift S, Focus 3, Steam Frame: Touch-like layout (Steam Frame: D-pad buttons = face buttons, bumpers = extra triggers).
Valve Index: thumbstick, not trackpad; quick right-grip tap = interact (A); left A = trap (X); left B = PKE (Y). Vive wands: trackpad =
stick; lower click = A, other click = stick click; menu = B / Y. Windows MR: stick, trackpad click = A. Anything else: stick found
automatically (controller_layout / stick_axis in gbvr_settings.txt can force it). Hand tracking is not supported: turn it off.
If something is wrong
• Black view: SteamVR and the headset must be running before the game starts. Choppy: VR SETTINGS > View > Resolution, press–, restart the game. Two graphics cards: set ghost.exe to High performance in Windows graphics settings.
• Bugs: close the game, double-click COLLECT_LOGS.cmd, send the zip from your Downloads folder plus a short video of the
headset view. README.txt has the full install steps and troubleshooting.
